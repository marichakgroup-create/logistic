# LoadLink workspace design

This direction supersedes the oversized hero surfaces and nested content sheets of Design v2 for authenticated screens. The user requested a ChatGPT-inspired SaaS workspace in LoadLink's own identity.

- White content canvas, quiet neutral sidebar, navy text and signal-yellow primary actions. Dark filled surfaces are optional emphasis, never the page background.
- Persistent three-item sidebar: Find, Trips, Account. Collapsible on desktop; mobile retains the three-item bottom navigation.
- Compact top context bar. Page title 30 px desktop / 26 px mobile, section title 18–24 px, body 14–16 px, supporting text 12–13 px.
- Manrope throughout. Weight 500 for navigation/body, 600–700 for headings and values. Prices use tabular figures.
- Surface hierarchy comes from whitespace, thin borders and restrained selected states. No giant nested gray sheets, decorative illustrations, or oversized titles.
- Controls 44 px minimum height, radius 10–12 px. Data cards 14 px, route composer 18 px. Visible keyboard focus and reduced motion remain enabled.
- Find uses a light route composer and readable freight cards. Trips has local status navigation and a separate result area. Account has anchored Vehicle / Plan / Workspace sections.
- UI UX Pro Max was read and its design-system search run for “logistics SaaS minimal workspace”. The Minimalism & Swiss Style match fits this operational product. Its landing-page pattern and blue/orange palette were excluded because they do not match the authenticated workspace or the user's existing brand.
