# Development plan

1. M0: workspace, containers, migrations, fixture adapter, reliable sync, cached routing and tests.
2. M1: passwordless sessions, van presets/onboarding, capacity-aware order search.
3. M2: pure matching rules and required tests, queued suggestions, builder, server validation.
4. M3: trip lifecycle, lost-order notifications, billing, event logging.
5. M4: real feed integration after legal verification, pilot and measured tuning.

Each milestone must pass typecheck, lint and logic tests. Container and browser acceptance are recorded separately; unverified checks do not count as complete.
